# Gymnis: лендинг фитнес-клуба (вёрстка по макету Figma)

Проект для портфолио: адаптивная вёрстка по бесплатному шаблону Figma Community «Gym Landing Page Template». Тексты переведены на русский, цены в рублях.

## Стек
- HTML5 (семантическая разметка)
- SCSS по методологии БЭМ (переменные, миксины брейкпоинтов)
- Vanilla JS (ES-модули), без фреймворков
- Vite 5 для сборки
- Шрифты: Unbounded (заголовки, в макете Syne, но в нём нет кириллицы; Syne оставлен для логотипа), DM Sans (текст), Google Fonts

## Запуск
```bash
npm install
npm run dev      # режим разработки
npm run build    # сборка в dist/
npm run preview  # просмотр сборки
```

## Что реализовано
- Навигация: на мобильных бургер-меню (aria-expanded, закрытие по Esc и по клику на пункт)
- Первый экран с тремя фото и градиентным заголовком
- Блок «О нас»
- Услуги: 4 рабочих таба (WAI-ARIA, переключение стрелками на клавиатуре)
- Отзыв клиента
- Форма записи в 4 шага: абонемент (месяц/год), способ оплаты, промокод (рабочий код `GYM10`, скидка 10%), итог с согласием с условиями
  - валидация на клиенте на каждом шаге, сообщения об ошибках через role="alert"
  - индикатор шагов, кнопки «Назад» / «Далее», пересчёт итоговой суммы
- Адаптив от 320 до 1920 px, focus-состояния, skip-link, alt у всех изображений, prefers-reduced-motion

Фото: Unsplash (бесплатная лицензия), обработаны в ч/б и лежат локально в `public/img` в формате WebP.
